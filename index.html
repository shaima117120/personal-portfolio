About Me

My name is Shaima Thapa Magar, and I am a student who is interested in learning web development and creating simple websites. This project is a personal portfolio website developed using semantic HTML5 elements as part of my academic work. The main goal of this project is to understand how to properly structure a webpage using meaningful tags like header, nav, main, section, article, and footer without using any CSS or styling. Through this project, I learned how to organize content clearly, create internal navigation links, display projects, and design a basic contact form while following proper HTML standards.
